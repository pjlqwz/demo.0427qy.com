========================================
三、设计要求
========================================

1. 纯静态网站，无表单、搜索等动态功能
2. 使用CDN加载jQuery、Bootstrap等公共库
3. 字体替换：微软雅黑 → 思源黑体 (Source Han Sans SC)
4. 响应式设计，适配移动端
5. 现代化、专业化的租车行业设计风格
6. 所有页面必须完善，不能欠缺

========================================
四、技术栈
========================================

- HTML5
- CSS3 (自定义样式 + Bootstrap 4.6.2)
- JavaScript (jQuery 3.6.4)
- Bootstrap 4.6.2
- Font Awesome 6.4.0
- Google Fonts (Noto Sans SC / Source Han Sans SC)

========================================
五、设计特点
========================================

1. 渐变色背景：深蓝色渐变作为主色调
2. 金色点缀：使用金色作为强调色
3. 卡片式设计：所有内容模块采用卡片式布局
4. 悬停效果：鼠标悬停时有上浮和阴影效果
5. 图标化：大量使用Font Awesome图标
6. 动画效果：CSS动画增强用户体验
